# PixProMint 

AI-powered Image Generator built using the MERN Stack.

## Live Demo
(Will be added after deployment)

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- OpenAI API

##  Features
- Generate images from text prompts
- Clean UI with Tailwind CSS
- Fast and responsive

##  Run Locally

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm run dev
